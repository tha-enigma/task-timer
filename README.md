# ⏱️ Task Timer (Replicon Edition)

A lightweight, cross-platform time tracking application built with HTML, JavaScript, and Electron. Designed for fast daily task logging and seamless export into Replicon timesheets.

---

## 🚀 Features

- **Real-time Tracking**: Start, pause, resume, and stop tasks with live duration displays.
- **Category Tagging**: Choose from pre-configured Replicon project categories.
- **Automatic Aggregation**: Instant daily and weekly totals grouped by task name.
- **Replicon CSV Export**: One-click export formatted specifically for Replicon timesheet imports.
- **Local Data Persistence**: Saves all entries locally—your data stays 100% private.

---

## 🛠️ How to Run Locally

### 1. In Browser / VS Code

Simply open `index.html` in Safari, Chrome, or VS Code Live Preview.

### 2. As an Electron Desktop App

Ensure you have Node.js installed, then run in your terminal:

````bash
# Install dependencies
npm install

# Start the desktop app
npm start
````
